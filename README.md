# hey, i'm malhar 👋

i'm an AI/ML engineer in mumbai. i like building AI stuff that actually ships: MCP tools, agent loops, eval harnesses, and full-stack apps that real people use. lately i've also been learning Go by building things that are probably overkill.

right now i'm tech lead at **[Valu Ventures](https://valu.ventures)**, a bootstrapped venture studio across Mumbai and Sydney. we launch a new online business every quarter and share the results in public.

- won 3 hackathons, including Best Blockchain Project at CSI-SPIT 2024 and 2nd runner up at IEEE Bombay Section
- shipped **[OmniHub](https://npmjs.com/package/omnihub-cli)** to npm and it crossed 1000+ downloads
- **[Wanderly](https://wanderly-weld.vercel.app)** is live and has real users planning real trips

## stuff i've built

| project | what it is | built with |
|---|---|---|
| [OmniHub](https://github.com/malharrrr/OmniHub) | MCP memory server for your AI assistants. sub-100ms semantic search, 1000+ npm downloads | TypeScript, Bun, Gemini API, MCP |
